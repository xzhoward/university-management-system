# Fullstack University Admin Dashboard

This is a full-stack admin dashboard project built using **React**, **Express**, and **PostgreSQL**. It allows administrators to manage university departments and faculty through a clean and intuitive interface.

### Live Demo
Access the live deployed version here:  
🔗 [https://venerable-lily-48078c.netlify.app/](https://venerable-lily-48078c.netlify.app/)

---

## Features
- View all departments and faculty
- Add/edit/delete departments
- Add/edit/delete faculty
- View department and faculty details
- Admin login functionality
- Clean responsive UI with custom CSS
